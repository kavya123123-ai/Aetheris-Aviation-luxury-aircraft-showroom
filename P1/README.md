# Aetheris Aviation | Luxury Private Jet Showroom

A high-fidelity, interactive luxury private jet showroom website designed for premium aerodynamics presentation, interactive cabin customization, and transcontinental range estimation. Built using clean, semantic, responsive front-end standards.

---

## 🌟 Immersive Interactive Features

### 1. Spec Showroom Lounge
A dynamic catalog of elite aircraft categories:
- **Aetheris Legacy 9000** (Ultra Long-Range Jet)
- **Aetheris Horizon X** (Super Midsize Jet)
- **Aetheris Solis** (eVTOL Electric Concept)

Clicking on any aircraft dynamically updates details, wingspan metrics, passenger capacities, and cruise speeds with smooth CSS progress transitions.

### 2. 360° Panoramic Cabin Simulator
Allows users to grab/drag or swipe horizontally inside a viewport to pan across a luxurious private cabin interior, simulating an onboard walk-through.

### 3. Cabin Customizer Workspace
Select interior parameters interactively:
- **Configurations**: Executive Lounge, Dining Suite, Master Bedroom.
- **Finishes**: Nappa Cream Leather, Carbon Slate, Royal Walnut, Satin Pearl.
- **Mood Lighting**: Sunset Gold, Aurora Cyan, Twilight Violet ambient overlays.

### 4. Mission Range Radar Estimator
An interactive tool mapping travel limits from select departure hubs (London, New York, Dubai, Tokyo, Singapore). Adjusting nautical miles renders a dynamic radial radar coverage circle over a high-tech SVG vector world map.

### 5. Multi-Step Inquiry Portal
A confidential acquisitions form wizard that routes user identification, selected airframe, and bespoke notes directly to the owner's mailbox (`pchaitra9876@gmail.com`) using FormSubmit.co.

---

## 🛠️ Technology Stack

- **Structure**: Semantic HTML5.
- **Styling**: Vanilla CSS3 using custom CSS variables (HSL design system tokens), custom scrollbars, fluid grid structures, and keyframe hover animations.
- **Logic**: Vanilla ES6 JavaScript (event listeners, Math scale operations, AJAX fetch POST queries).
- **Backend API**: FormSubmit.co integration for zero-server client form submissions.

---

## 🚀 Setup & Execution

To run the project locally without errors:
1. Open the project folder in **Visual Studio Code**.
2. Install the **Live Server** extension.
3. Open `index.html` and click **Go Live** on the bottom status bar.
4. Access the local host URL in any web browser.
